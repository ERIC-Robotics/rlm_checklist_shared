1. System Overview

RailwayMitra is a field trial management platform for ERIC Robotics. Field engineers fill trial checklists, PMO manages agendas, and leads receive automated email summaries on submission.

3. Trial Submission Flow

User fills checklist (Sections 1 to 4)
Auto-save on every answer change
saveTrial() → localStorage + queueRemoteTrialSave()
PUT /api/trials/:trialId (debounced 500ms)
Click "Submit Post-Trial"
submitPostTrial() in ChecklistApp.jsx
1. saveTrial() locally (submitted: true)
2. PUT /api/trials/:trialId → mark submitted in DB
Fail
Show toast, STOP
Success
3. POST /api/submit-trial
getSessionEmployee() verify cookie
formatTrialSummary() build email
sendTrialPdfEmail() → TRIAL_REPORT_EMAIL
4. router.push("/history")

7. Role-Based Access

Regular Employee

  • Fill checklist (Sections 2, 3, 4)
  • View agenda (read-only)
  • Submit Pre-Trial
  • Submit Post-Trial
  • Raise support tickets
  • View trial history

PMO (codes: 2440, 16080)

  • All regular employee permissions
  • Edit Trial Agenda (Section 1)
  • Submit Agenda to Trial List
  • Print Acknowledgment (full Aadhaar)
  • Access admin panel
